How to Use MG BOT Pro

Follow these steps to start generating high-accuracy technical analysis signals for Forex, Crypto, and Binary trading.

Quick Start (3 Steps)

1

Select Your Market & Asset

Go to the Signal Terminal tab. Select Forex, Crypto, or Binary from the market tabs, then choose your trading pair from the dropdown (e.g. EURUSD, BTCUSDT).

Best for beginners: Start with major forex pairs like EURUSD or GBPUSD during the London session (07:00–12:00 UTC) for the highest liquidity.
2

Choose Your Timeframe

Select a timeframe on the chart toolbar. For scalping, use 1M or 5M. For short-term trading, use 15M or 30M. For swing trades, use 1H or 4H.

Binary options: Use 5M chart and set expiry to the suggested expiry shown after analysis. Never trade binary options on 1M — too much noise.
3

Click "Analyse & Get Signal"

Press the blue button. The bot fetches live data, runs all 12 indicators, performs multi-timeframe analysis and displays a BUY (UP) or SELL (DOWN) signal with confidence percentage.

Only act on STRONG signals with 65%+ probability. Skip WEAK signals or when the score says "NO TRADE".

Setting Up Live Data (Optional but Recommended)

4

Get a Free TwelveData API Key (Forex only)

For Forex and Binary signals, MG BOT Pro uses the free TwelveData API. Without a key it uses a demo key (limited). Crypto always uses Binance directly (no key needed).

  1. Visit twelvedata.com and register for free
  2. Copy your API key from the dashboard
  3. Paste it in the API key field on the Terminal and click Save
Crypto users: No API key needed at all. Binance data is fetched automatically and is always live.
